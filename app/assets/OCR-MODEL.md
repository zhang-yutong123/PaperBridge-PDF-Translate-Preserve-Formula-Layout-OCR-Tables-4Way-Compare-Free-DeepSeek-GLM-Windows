# OCR model source

`en_PP-OCRv4_rec_mobile.onnx` is the English PP-OCRv4 recognition model distributed by RapidAI for RapidOCR.

- Project: https://github.com/RapidAI/RapidOCR
- Model catalog: https://rapidai.github.io/RapidOCRDocs/main/model_list/
- Model: https://modelscope.cn/models/RapidAI/RapidOCR/resolve/master/onnx/PP-OCRv4/rec/en_PP-OCRv4_rec_mobile.onnx

The installed RapidOCR detector and this recognizer run locally. Text is then sent to the translation provider selected in the desktop application.
