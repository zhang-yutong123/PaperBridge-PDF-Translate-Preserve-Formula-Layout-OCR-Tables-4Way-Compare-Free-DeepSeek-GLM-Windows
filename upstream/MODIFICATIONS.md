# 随发行版提供的上游源码

本目录保存当前社区桌面发行版源码归档中的 Python 源码快照：

- `pdf2zh/`：PDFMathTranslate / pdf2zh 1.9.11。
- `babeldoc/`：BabelDOC 0.2.33。

它们是当前安装包所对应的本地源码快照，可能包含本地修改；并不宣称与相同版本号的 PyPI 包逐字相同。原有代码与许可证归其原作者所有，按各自上游 AGPL-3.0 许可证提供。

社区桌面版主要集成与修复逻辑保存在 `app/`：中文设置和四种预览、翻译服务配置、请求行为调整、页码与输入处理、原生公式保留、图片文字/OCR、表格和图形区域处理。`app/app.py` 还会在加载时对 `pdf2zh.gui` 的桌面集成部分应用本地适配。

复现当前发行版时，应先安装 `requirements.txt` 中的依赖，再把这里的源码覆盖到虚拟环境对应的 `pdf2zh` 与 `babeldoc` 包中，以保留已安装依赖包的元数据和其他资源。参见 `packaging/BUILD.md`。
