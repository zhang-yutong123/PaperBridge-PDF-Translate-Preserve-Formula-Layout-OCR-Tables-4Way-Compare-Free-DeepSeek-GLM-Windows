# 论文 PDF 翻译 · Windows 分享版

双击 `PDF论文翻译-安装.exe`，会把程序安装到当前用户的
`%LOCALAPPDATA%\Programs\PDF2ZH\2026.10.17.1`，并创建桌面“PDF论文翻译”快捷方式。
无需另外安装 Python、Codex 或 PowerShell 模块。首次准备模型后会自动打开浏览器；之后双击桌面快捷方式即可。

默认使用无需 API Key 的必应翻译，需要联网。可以在页面内选择 DeepSeek、智谱 GLM 等服务并填写自己的 API Key。
配置、缓存和翻译结果放在 `%LOCALAPPDATA%\PDF2ZH`，不会写入安装包。
分享包不包含制作者的 API Key、历史翻译或 PDF 文件。网页版只监听当前电脑的 `127.0.0.1:7868`。

这是独立打包的社区版本，基于 PDFMathTranslate 1.9.11 加入中文界面、对照阅读和排版修复。
它不是 PDFMathTranslate 官方发布的 Windows 程序。程序没有商业代码签名证书，Windows 可能提示发布者未知；
Smart App Control 开启的电脑也可能阻止未签名程序，此安装包不修改系统安全设置。

PDFMathTranslate、BabelDOC、PyMuPDF/MuPDF 使用 AGPL-3.0 等上游许可证；其余依赖遵循各自许可证。
界面与本地修复源码、构建脚本、上游 PDFMathTranslate Python 源码及第三方许可证在安装目录的
`源码与许可证.zip`。继续分享本程序时，请保留该文件。
